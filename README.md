# 天气数据分析系统 (Weather Data Analysis System)

**Student ID:** 20230929

## 如何运行项目 (How to run the project)

This project is built with Vue 3 and Vite. You need Node.js installed to run it.

### 步骤 1: 安装依赖 (Install dependencies)
Open the terminal in the project folder and run:
npm install

### 步骤 2: 启动开发服务器 (Start development server)
npm run dev

### 步骤 3: 在浏览器中打开 (Open in browser)
Open the link shown in the terminal (usually http://localhost:5173/)

---

## 生产环境构建 (Production Build - Optional)
If you want to run it without Node.js:
1. Run: npm run build
2. Open the generated `dist/index.html` file in your browser.
